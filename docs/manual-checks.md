# 1.1.4 手测清单

本次重点：工作室与作品页统一通过 MT 管理器导入；作品页右上角新增加号。

1. 在工作室点加号，应打开 MT 管理器；选择一个音频或视频后，回到工作室并出现新工程。
2. 在“我的作品”右上角点加号，同样通过 MT 导入；空列表也应显示加号和导入按钮。
3. 打开 MT 后取消选择，应返回原页面，不新增空工程、不改变已有作品。
4. 如果首次使用尚未授权 Sounds，会先出现系统目录授权；授权完成后再进入 MT 选择音视频。已授权的手机直接打开 MT。

未安装或无法调用 MT 的设备会回退到系统选择器。本次未操作文件选择界面，手测由用户完成。

## 之前改动的回归检查

直接用已有作品检查即可：

1. **同一作品返回**：工作室打开 A → 进入作品 → 点击 A，应立即回到工作室。切换到 B 也应正常跳转。原声对比开启时重复打开 A，开关和实际播放状态应一致。
2. **工作室标题**：应显示“可可的声音工作室”，大字体下也应正常排版。
3. **原声对比开关**：关闭时为淡青蓝色，开启时为实色青蓝。浅色、深色模式都应与页面主色协调。
4. **自由混音**：没有独听按钮；音量、静音、只听人声、只听伴奏仍可使用。旧工程的独听标记不再影响试听和导出。
5. **作品卡片**：按住文字区或卡片空白处，反馈应覆盖整个圆角卡片并贴合边界；松手能打开作品。点击删除图标只弹删除确认，不跳进工作室。
6. **作品页面**：“我的作品”下方没有“工程目录”说明；删除确认中的“删除”为红色，“保留”保持普通按钮颜色。
7. **设置**：没有 Radiant 开关，固定使用 Radiant；原先关闭该选项的旧安装也应自动启用。明暗模式仍可选择，主题色不跟随壁纸。
8. **保存回归**：调整一个比例、切换作品再返回，确认数值保留；默认导出仍在 `/storage/emulated/0/Sounds/`，公共工程仍在 `Sounds/VoiceFocus/Projects/`。
