# 1.1.1 手测清单

本次范围：仅将底部导航替换为安大通 Radiant 的 UI 与动画；按钮、页面配色和其他界面样式恢复第一版。保留 Sounds 默认保存目录。

直接用已有作品检查即可：

1. **界面恢复**：导入、导出、播放、静音、独听、百分比等按钮，以及页面配色，应与第一版一致。
2. **底部导航**：点击工作室/作品/设置；按住选中项、左右拖动再松手。检查切换页面正确，按压、形变、拖动、回弹无卡住或明显重影。
3. **默认导出**：打开已有作品，导出面板保持“保存到 Sounds”，任选 WAV/M4A。完成后在文件管理器的 `/storage/emulated/0/Sounds/` 中找到新增文件并播放。
4. **作品工程**：检查 `/storage/emulated/0/Sounds/VoiceFocus/Projects/`，工程文件夹应含原始文件、原音 WAV、独立声部 WAV 和 `project.json`。本机已有四个工程已同步。
5. **配比保存**：改变一个比例，切换到其他项目再返回，确认数值保留；重新导出确认变化生效。
6. **另存为**：导出面板选“另存为…”，检查可以自行选择目录，默认保存选项仍是 Sounds。

反馈问题时写明：操作步骤、预期结果、实际现象；有截图或录屏可一起提供。
