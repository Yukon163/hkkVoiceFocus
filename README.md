# KK Voice Focus

一款在 Android 手机上离线分离、调整和导出人声与乐器声的音视频处理应用。

## 功能

- 导入音频或视频文件；优先使用 MT 管理器选择文件，MT 不可用时自动使用系统文件选择器。
- 支持从工作室和“我的作品”页面创建新作品，也支持接收其他应用分享的音视频。
- 弹唱模式将声音分为人声和完整伴奏，适用于钢琴、电子琴、吉他和尤克里里弹唱。
- 多乐器模式可分别调整人声、吉他、钢琴、鼓、贝斯和其他声部。
- 每条音轨支持 0–200% 音量调节、精确百分比输入和静音。
- 提供人声突出、原始比例、只听人声、只听伴奏等快捷配比。
- 支持实时试听、波形定位和原声对比。
- 支持导出 WAV、M4A、保留原画面的 MP4，以及包含独立分轨的 ZIP。
- 默认将导出文件保存到 `/storage/emulated/0/Sounds/`，也可选择其他保存位置。
- 作品工程、原始文件、分轨和配比保存在 `Sounds/VoiceFocus/Projects/`，支持重新打开、同步、恢复和删除。
- 首次下载模型后可完全离线处理，导入的音视频不会上传服务器。
- 分离和导出可在后台继续运行，支持查看进度和取消任务。
- 固定使用 Radiant 界面，支持浅色、深色和跟随系统明暗模式。

## 支持的内容

- 常见音频：MP3、AAC/M4A、WAV、FLAC、Ogg。
- 常见视频：MP4、MKV、WebM。
- 实际可用格式取决于设备内置的媒体解码能力。
- 当前模型没有独立的尤克里里声部；尤克里里弹唱建议使用“人声 + 完整伴奏”模式。
- 分离效果会受到现场混响、背景噪声和多个乐器同时演奏的影响。
